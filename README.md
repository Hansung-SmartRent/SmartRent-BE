# SmartRent Backend

학교 기자재를 앱에서 조회·예약하고, AI 인식과 QR로 대여·반납하는 기자재 대여 서비스 SmartRent의 백엔드 API 서버입니다.

## 주요 기능

- **기자재 조회·예약**: 기자재 목록·검색·상세, 날짜·시간 예약, 시간 겹침 방지
- **AI 기자재 인식**: 앱에서 촬영한 기자재를 인식하고, 인식 결과로 기자재 정보를 조회
- **QR/바코드 대여**: 기자재마다 부착된 고유 코드로 대여·반납 처리
- **반납·연장·연체**: 반납 사진 첨부, 다음 예약 기준 연장 가능 여부 판단, 연체료 계산
- **반납 예정 알림**: 반납 기한이 가까워지면 푸시 알림 발송
- **내 대여 현황/이력**: 대여 중 목록, 지난 대여 이력
- **기자재 상태 신고**: 고장·파손 신고 접수 및 관리자 처리
- **AI 기자재 추천**: 사용 목적을 입력하면 적합한 기자재 추천
- **대여 통계**: 기자재별·기간별 대여 현황 (관리자)

## 기술 스택

| 구분 | 내용 |
|---|---|
| 언어 | Java 21 |
| 프레임워크 | Spring Boot (버전 미정) |
| 빌드 | Gradle |
| DB | MySQL 8.0 |
| ORM | Spring Data JPA |
| 검증 | Bean Validation |
| 인증 | Spring Security + JWT |
| API 문서 | springdoc-openapi (Swagger) |
| 푸시 알림 | Firebase Cloud Messaging (FCM) |
| AI 추천 | 언어 모델 API (미정) |
| 테스트 | JUnit 5 |

## 프로젝트 구조

```
src/main/java/(패키지명 미정)/
├── global/
│   ├── config/          # 보안, Swagger 등 설정
│   ├── security/        # JWT 발급·검증
│   ├── exception/       # 공통 예외, 에러 코드, 전역 예외 처리
│   └── response/        # 공통 응답 포맷
└── domain/              # 도메인별 controller → service → repository → entity → dto
    ├── auth/            # 회원가입, 로그인
    ├── user/            # 유저 정보, 학생/관리자 권한
    ├── equipment/       # 기자재 모델·개별 기기, QR 코드, 인식 결과 조회
    ├── recommendation/  # AI 기자재 추천
    ├── issue/           # 기자재 상태 신고
    ├── upload/          # 사진 업로드
    ├── rental/          # 예약, 수령, 반납, 연장, 연체
    ├── notification/    # 알림 저장·발송
    ├── statistics/      # 대여 통계
    └── notice/          # 공지사항
```

## 시작 가이드

필요한 환경변수:

| 키 | 설명 |
|---|---|
| DB_URL | MySQL 접속 주소 |
| DB_USERNAME / DB_PASSWORD | MySQL 계정 |
| JWT_SECRET | 토큰 서명 키 |
| FCM 키 파일 경로 | 푸시 알림 발송용 (미정) |
| 언어 모델 API 키 | AI 추천용 (미정) |

개발 서버 실행:

```
./gradlew bootRun
```

- API Base URL: http://localhost:8080/api/v1
- Swagger UI: http://localhost:8080/swagger-ui/index.html

테스트:

```
./gradlew test
```

## 공통 응답 / 에러 포맷

모든 API는 아래 형식으로 응답합니다.

```json
{ "success": true, "message": "...", "data": { }, "errorCode": null }
```

에러 코드는 `VALIDATION_ERROR`, `UNAUTHORIZED`처럼 대문자와 밑줄로 쓴 문자열 상수를 사용합니다.
